Якщо ти вже створив файли на комп'ютері (написав код) і паралельно створив репозиторій на сайті GitHub, їх треба просто «зв'язати» між собою.

Головне правило: Щоб цей спосіб спрацював без помилок, створений репозиторій на сайті GitHub має бути абсолютно порожнім (коли створював, ти НЕ ставив галочку біля Add a README file).

Ось як це зробити прямо у VS Code без зайвого болю:

Крок 1: Зберігаємо код (Коміт) у VS Code
Спочатку треба сказати локальному Git на комп'ютері, що ми хочемо зберегти ці файли.

Відкрий свою папку з кодом у VS Code.

Перейди у вкладку Source Control (іконка з гілочкою зліва).

Натисни синю кнопку Initialize Repository (якщо ще не натискав).

Наведи на рядок Changes і натисни (+), щоб додати всі файли до підготовки.

У поле Message напиши Pierwszy commit і натисни кнопку Commit.

Тепер код збережено, але він усе ще тільки на цьому комп'ютері.

Крок 2: Копіюємо посилання з GitHub
Відкрий свій створений репозиторій на сайті GitHub.

Оскільки він порожній, ти побачиш сторінку з підказками і кодами. Знайди блок Quick setup (саме верхнє посилання) і скопіюй його (воно закінчується на .git, наприклад: [https://github.com/TviyLogin/NazvaRepa.git](https://github.com/TviyLogin/NazvaRepa.git)).

Крок 3: Зв'язуємо VS Code із GitHub
Повертаємося у VS Code. Робимо магію зв'язування через інтерфейс:

У вкладці Source Control (там, де гілочка) подивись у самий верх цієї панельки. Там є іконка з трьома крапками (...). Натисни на неї.

У меню вибери Remote (Віддалені) -> потім Add Remote... (Додати віддалений...).

Згори по центру з'явиться поле вводу. Встав туди скопійоване посилання з GitHub і натисни Enter.

Далі VS Code попросить ввести назву для цього посилання. Напиши слово origin (це стандартна назва в програмуванні) і знову натисни Enter.

Крок 4: Закидаємо файли на сайт
Тепер у тебе в панелі Source Control з'явиться кнопка Publish Branch (Опублікувати гілку).

Натисни її.

Якщо вискочить віконце з питанням, куди саме відправити, вибери той самий origin, який ти щойно створив.

Все! Можеш оновлювати сторінку свого репозиторію на сайті GitHub — твої файли index.html та style.css вже там.







Так, абсолютно! Це найпростіший, "аварійний" спосіб, якщо термінал або VS Code відмовляються працювати, а оцінку отримати треба.

Ти можеш зробити все прямо в браузері на сайті GitHub: завантажити файли, створити гілки і зробити злиття. На сайті все влаштовано як у звичайному Google Диску.

Ось як це робиться без жодних команд:

1. Як закинути файли через сайт (Upload files)
На сайті GitHub створи новий репозиторій. Важливо: цього разу обов'язково постав галочку біля Add a README file. Це потрібно, щоб репозиторій не був порожнім і одразу з'явився інтерфейс для завантаження.

Коли репозиторій відкриється, ти побачиш кнопку Add file (Додати файл) над списком файлів. Натисни на неї.

Вибери Upload files (Завантажити файли).

Просто перетягни мишкою свої файли (index.html та style.css) з комп'ютера у вікно браузера (або натисни choose your files і вибери їх).

Внизу сторінки є поле Commit changes. Напиши туди повідомлення (наприклад, Dodanie plikow startowych).

Натисни зелену кнопку Commit changes.
Усе, твої файли вже на сайті!

2. Як створити гілку (Branch) через сайт
Викладач просив показати роботу з гілками? Це теж робиться у два кліки:

На головній сторінці твого репозиторію зліва зверху є кнопка, на якій написано main (це твоя головна гілка). Натисни на неї.

Відкриється віконце з пошуком. Прямо туди впиши назву нової гілки, наприклад nowa-funkcja.

Знизу з'явиться синій рядок Create branch: nowa-funkcja from 'main'. Натисни на нього.
Гілку створено, і сайт автоматично переключив тебе на неї.

3. Як змінити код у новій гілці
Переконайся, що зліва зверху вибрана твоя нова гілка (nowa-funkcja).

Натисни на свій файл, наприклад style.css, щоб він відкрився.

Справа зверху над кодом є іконка Олівця (Edit). Натисни її.

Допиши або зміни якийсь код (наприклад, поміняй колір).

Натисни зелену кнопку Commit changes (справа зверху). У віконці, що з'явиться, знову напиши повідомлення і підтверди.

4. Злиття гілок (Pull Request)
Щоб об'єднати твою нову гілку з основною базою:

Повернися на головну сторінку репозиторію.

GitHub сам побачить, що ти щось робив у іншій гілці, і покаже велику жовту/зелену плашку з кнопкою Compare & pull request. Натисни її.

Далі просто тиснеш зелені кнопки по черзі: Create pull request -> Merge pull request -> Confirm merge.























Зрозумів. Ситуація, коли ти сідаєш за чужий (університетський) комп'ютер, дійсно відрізняється. Головна проблема там — авторизація. Якщо намагатися створювати репозиторій локально на комп'ютері, VS Code може почати видавати помилки прав доступу, бо не знає, хто ти такий.

Тому на екзамені ми змінимо тактику: спочатку створимо все на сайті, а потім "скачаємо" у VS Code. Це найбільш безвідмовний метод.

Ось покроковий план, як усе зробити з абсолютного нуля на чужому комп'ютері.

Крок 1: Вхід у систему (Авторизація)
Відкрий браузер і увійди у свій акаунт на сайті github.com.

Відкрий VS Code. Подивись у самий низ лівої панелі — там є іконка профілю (чоловічок). Натисни на неї.

Вибери Sign in with GitHub. Відкриється вікно браузера, де треба буде натиснути зелену кнопку Authorize. Тепер VS Code знає, що ти — це ти.

Крок 2: Створення репозиторію на сайті GitHub
Замість того, щоб мучитися з папками на комп'ютері, робимо так:

На сайті GitHub (на головній сторінці або у профілі) натисни зелену кнопку New.

У полі Repository name напиши назву (наприклад, kolokwium-web).

Обов'язково постав галочку біля Add a README file. Це створить перший файл, щоб репозиторій не був порожнім (це важливо для наступного кроку).

Опустися вниз і натисни Create repository.

На сторінці твого нового репозиторію натисни зелену кнопку <> Code і скопіюй посилання (воно виглядає як [https://github.com/](https://github.com/)...).

Крок 3: Перенесення в VS Code (Клонування)
Тепер "скачуємо" твій проєкт із сайту на екзаменаційний комп'ютер.

У VS Code відкрий третю вкладку зліва — Source Control (іконка з гілочкою).

Натисни велику синю кнопку Clone Repository (Клонувати репозиторій).

Зверху з'явиться поле вводу. Встав туди скопійоване посилання і натисни Enter.

VS Code відкриє вікно — вибери папку на комп'ютері (наприклад, "Робочий стіл"), куди хочеш зберегти проєкт, і натисни Select as Repository Destination.

У правому нижньому куті вилізе віконце. Натисни Open, щоб відкрити цю папку у VS Code.

Все! Тепер ти працюєш у папці, яка офіційно зв'язана з твоїм GitHub.

Крок 4: Робота і перший коміт (на оцінку 3.0)
Створи файли index.html, style.css, напиши код і збережи їх (Ctrl+S).

Зайди у вкладку Source Control (гілочка зліва). Ти побачиш свої нові файли у списку "Changes".

Наведи мишкою на слово "Changes" і натисни плюсик (+). Файли перемістяться вище в "Staged Changes".

У поле Message напиши, що ти зробив (наприклад: Dodanie HTML i CSS).

Натисни велику синю кнопку Commit (або галочку зверху).

Тепер натисни велику синю кнопку Sync Changes (Синхронізувати).
Готово! Твій код полетів на сайт GitHub.

Крок 5: Робота з гілками (на оцінку 4.0 і 5.0)
Викладач просить показати роботу з гілками. Робимо фіктивну "нову функцію":

У VS Code в самому низу ліворуч на синій смужці натисни на слово main.

Зверху випаде меню. Вибери + Create new branch.

Назви її (наприклад: dodanie-js) і натисни Enter. Зверни увагу: слово main внизу змінилося на dodanie-js.

Відкрий свій файл, допиши туди якийсь JavaScript (або просто зміни колір у CSS) і збережи.

Знову йди в Source Control, тисни (+), пиши повідомлення (Dodanie logiki) і тисни Commit.

З'явиться синя кнопка Publish Branch. Натисни її, щоб ця нова гілка відправилася на GitHub.

Крок 6: Злиття (Merge) через сайт
Найбезпечніше зливати гілки прямо на сайті, щоб викладач бачив історію.

Зайди на свій репозиторій на сайті GitHub.

Сайт сам побачить твою нову гілку і покаже велику жовту або зелену плашку з кнопкою Compare & pull request. Натисни її.

На наступній сторінці натисни зелену кнопку Create pull request.

Потім натисни Merge pull request і Confirm merge.
Твоя нова гілка успішно додана до основного коду!

⚠️ Важливо для безпеки в університеті
Коли закінчиш колоквіум, не забудь вийти зі свого акаунта на цьому ПК!

У VS Code: натисни на іконку профілю (чоловічок) внизу зліва і вибери Sign out.

У браузері: вийди з акаунта на сайті GitHub.

Чи зрозумілий цей шлях від створення репозиторію на сайті до клонування у VS Code, чи якийсь із кроків варто розібрати детальніше?
